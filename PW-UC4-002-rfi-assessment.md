# PW-UC4-002 – RFI Response Completeness Assessment

## Business Area
Private Wealth

## Status
Proposed

## Capability

- Comparison
- Gap Analysis
- Document Review

## Intent

Support case officers to assess whether taxpayer responses address each question in the original Request for Information (RFI).

The objective is to reduce manual review effort while improving traceability.

## Inputs

### Original RFI

- Questions issued by the case officer

### Taxpayer Response

- Response letter
- Supporting documents

Examples:

- Bank statements
- Financial statements
- Loan agreements
- Contracts
- Trust deeds
- Minutes
- Organisation charts

## Expected Outcome

Table containing:

- Original question
- Response summary
- Answered / Partially Answered / Unanswered
- Supporting evidence references
- Missing information
- Potential inconsistencies
- Evidence gaps

## Benefits

- Improved traceability
- Reduced review effort
- Greater consistency
